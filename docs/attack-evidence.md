# Offline controlled attack evidence

Build the contracts, inspection and agent packages with `npm run build --workspace @trendie/contracts`, `npm run build --workspace @trendie/inspection`, and `npm run build --workspace @trendie/agent` under Node 22, then run `npm run demo:controlled` (attack) and `npm run demo:controlled -- --clean` (compliant candidate). The CLI imports this checkout's built `packages/agent/dist/index.js`. Use a normal workspace installation so its transitive contracts and inspection imports also resolve to this checkout. It uses only synthetic in-process fixtures and performs no network, gateway, wallet, provider, or settlement operation.

The output contains `modelMode` (`fixture` for this run), `evidence`, `vulnerableSimulation`, and `protectedPolicy`. Evidence version 1 records a UUID attempt identifier, source references, bounded inspection limit and findings with source spans, SHA-256 listing-content digest, canonical proposal fingerprint, trusted owner/intent/version binding, and model input/output. The validator recomputes content digest, inspection, offsets, and proposal fingerprint and rejects unsupported envelope fields.

Acceptance cases are in `packages/agent/src/__tests__/controlled-comparison.test.ts`: malicious candidate rejected by fixture policy, compliant candidate approved without settlement, missing provenance rejected, evidence tampering/accessors rejected, bounded inspection and offsets verified, mutable inputs snapshotted, gateway input frozen, malformed responses sanitized, and one shared timeout enforced.

The vulnerable path is a labeled simulation record only (`executed: false`, `providerDispatch: false`). A policy rejection is not evidence of execution prevention, settlement behavior, or resistance by a live LLM. The deterministic fixture model proposes a fixed candidate; injected mode is only a caller-provided model port. Neither mode proves model behavior. Inspection findings are advisory. The fixture policy independently checks seller, item, amount, scale, asset, and configured recipient against trusted fixture values.

No live or paid call is authorized by this CLI.
